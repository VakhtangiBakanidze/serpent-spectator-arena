# Serpent Spectator Arena

Create a snake game with two models: pass-though and walls. prepare to make it multiplayers - we will have this functionality: leaderboad and watching (me following other players that currently play). add mockups for that and also for log in.

everything should be interactive - I can login, sign up, see my username when I'm logged in, see leaderboard, see other people play (in this case just implement some playing logic yourself as if somebody is playing) make sure all the logic is covered with tests.

don't implement backend, so everything is mocked, But centralize all the calls to the backend in one place.
